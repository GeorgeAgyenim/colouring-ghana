## Assumptions stated during the session (not separately decided)

- Feature slug `map-migration`; ticket paths `docs/tickets/map-migration/issues/NN-<slug>.md`.
- The Leaflet tree is left untouched behind the flag until ticket 01 removes it.
- Tile zoom range matches today: data from zoom 9, tippecanoe max zoom 16 with MapLibre overzoom to 19; exact settings benchmarked.
- The archive is built so `pmtiles extract` can clip a district for packs (FR-10.2) without a rebuild.
- Three themes (light, night, night_outlines) are three style variants from the one style config.
- Boundary layers, search pins and the geolocation control are ported to `@vis.gl/react-maplibre` with the same behaviour (zoom-dependent labels, permanent tooltips become symbol layers).
- The edits-since endpoint returns geometry and styled attributes only, capped, no contributor identity; it carries a short statement timeout like other interactive endpoints.
- The client fetches the manifest at page load and after each save to learn the archive's "as of".
- Only three code paths consume `/tiles/` today (`server.tsx`, the edit-service tile-cache expiry, `get-tile-layer-url.ts`); all go with ticket 01.

## Corrections made by the product owner during the session

Recorded here so the reasoning behind ADR-0024, the OSM inventory entry and the benchmark method is traceable.

### cross-artefact consistency (P5)
- Pattern: proposed a PMTiles export job in isolation; user pointed out tiles and the GeoParquet snapshot
  must share one "as of" or a result view could highlight buildings the tiles do not show.
- Rule: before recommending any data artefact, check it against P1–P9 and every sibling artefact that a
  user could see side by side. Anything time-stamped must come from one transaction with siblings.

### statement timeout is not a bulk-export guard
- Pattern: suggested a statement timeout on the export role, echoing NFR-2.5's wording. User: it kills the
  export the day the data grows; intent is "never block contributors".
- Rule: read a requirement's intent, not its example mechanism. For bulk reads use a dedicated role,
  generous timeout, nice/ionice, quiet run window; keep short timeouts for interactive endpoints.

### inherited third-party data flows
- Pattern: claimed "no privacy-notice change in E0" because E0 adds no new host; user: the OSM tile host
  already sees zoom-19 requests, so FR-14.11.c applies today and E0 does not exempt it.
- Rule: when assessing a change's privacy impact, list every third-party host the baseline already contacts;
  "no new flow" is not "no disclosure needed". Record inherited services in the tool inventory.

### bandwidth is the binding constraint
- Pattern: proposed a latency-only benchmark; user: bandwidth, not latency, binds in Ghana; record bytes per step.
- Rule: any performance method for this project records bytes transferred beside every timing, includes a
  throttled reproducible run, and sets targets from a recorded baseline rather than a guess.
